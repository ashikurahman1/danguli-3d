# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Danguli 3D**, please report it responsibly:

1. Open a GitHub Security Advisory on the repository or email the maintainers directly.
2. Please provide detailed reproduction steps, browser/platform environment, and potential impact.
3. Allow the maintainers reasonable time to investigate and address the vulnerability before public disclosure.

We appreciate your assistance in keeping our players and community safe.
