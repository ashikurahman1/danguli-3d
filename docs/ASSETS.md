# Asset Attribution & Licenses — Danguli 3D

All 3D geometries, materials, shaders, and UI icons in **Danguli 3D** are procedural or original vector creations.

## 1. 3D Geometries & Materials

- **Guli (Biconical piece)**: Procedural `THREE.LatheGeometry` based on authentic South Asian proportions (12cm length, 3cm center diameter, 3mm tapered tips). Created originally for this project.
- **Danda (Striking stick)**: Procedural `THREE.LatheGeometry` sculpted with rounded pommel grip, transition neck, and striking head. Created originally for this project.
- **Garti (Ground pit)**: Procedural `THREE.CylinderGeometry` scaled to an elliptical depression.
- **Ground & Pebbles**: Procedural `THREE.PlaneGeometry` with vertex undulations and `THREE.InstancedMesh` dodecahedral pebbles.
